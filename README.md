# Sales Medallion on dbt + Databricks

Same medallion pattern as the other repos here (bronze → silver → quarantine →
gold), built with **dbt** instead of hand-written SQL scripts — snapshots for
history, generic + singular tests as the quality gate, and a lineage graph
dbt generates for free instead of a diagram someone has to maintain by hand.

The dataset is synthetic sales data (customers, products, orders, order
items), generated locally with a fixed random seed and a known, counted set
of defects seeded into it on purpose — so the tests below have something
real to catch instead of passing trivially on clean data.

## Why dbt here, when the other repos are plain SQL

`data-lab2` and `fhir-dataset` build bronze/silver/quarantine/gold as
hand-sequenced SQL scripts and a bespoke quarantine table. This repo is the
same idea through a tool built for exactly this: lineage, tests, and history
come from dbt's framework instead of being written and maintained by hand.
Both approaches are deliberate, not one superseding the other.

## Architecture

```
seeds/raw_*.csv  (bronze: loaded as-is via `dbt seed`)
       │
       ▼
models/staging/stg_*            (silver: cast + rename, 1:1 with the source)
       │
       ▼
models/intermediate/int_*_valid      ──┐
models/intermediate/int_*_quarantine ──┘  (split, with a reason column)
       │
       ▼
models/marts/core/fct_*, dim_*  (gold: only built from *_valid)
       │
       ▼
tests/assert_quarantine_rate_is_sane.sql   (gate: fails the build if too
                                             much is landing in quarantine)
```

`snapshots/customers_snapshot.sql` keeps SCD Type 2 history of each
customer's `segment`/`state` across snapshot runs, instead of overwriting the
old value.

## Repo layout

| Path | Contents |
|---|---|
| `seeds/` | Synthetic raw CSVs (bronze), regenerated by `scripts/generate_synthetic_data.py` |
| `models/staging/` | 1:1 cast/rename of the raw seeds |
| `models/intermediate/` | Dedupe + valid/quarantine split, with a reason per rejected row |
| `models/marts/core/` | Gold: dimensions and facts, built only from the `*_valid` models |
| `snapshots/` | SCD Type 2 history of customer attributes |
| `tests/` | The singular quarantine-rate gate (generic tests live next to each model in `_*.yml`) |
| `scripts/generate_synthetic_data.py` | Regenerates `seeds/` deterministically (seeded RNG) |

## The data, measured

Generated once, counted, written here — not guessed:

- **40 customers**, **15 products**
- **258 orders**: 250 clean + **5** with a `customer_id` that matches no
  customer + **3** duplicate `order_id` rows (a re-extract style defect)
- **662 order items**: incl. **8** with a non-positive quantity and **2**
  with a `product_id` that matches no product

Re-run `python scripts/generate_synthetic_data.py` to reproduce the exact
same numbers (fixed seed) or change the seed/counts to generate a different
dataset.

## Status

Run end-to-end against a real Databricks SQL warehouse (trial workspace,
Unity Catalog `workspace`) — `dbt seed`, `dbt run`, `dbt test`, `dbt
snapshot` all completed successfully:

- **13 of 13 models** built (9 views, 4 tables)
- **31 of 31 tests passed**, including the quarantine-rate gate
- Of the seeded defects: **5 of 5** orphan-customer orders and **10 of 10**
  bad-quantity/orphan-product order items landed in quarantine with a
  reason, exactly as designed - nothing silently dropped, nothing silently
  let through
- Gold layer: **643 valid order-item rows**, **$290,157.21** total revenue
  (`fct_daily_sales`)
- `customers_snapshot` ran and recorded SCD2 history

## Running it

```bash
pip install dbt-databricks
cp profiles.yml.example ~/.dbt/profiles.yml   # uses OAuth, not a token - see the file

# set DATABRICKS_HOST / DATABRICKS_HTTP_PATH for your workspace, then:
dbt debug                # confirms the connection
dbt deps                 # installs dbt_utils
dbt seed                 # loads seeds/raw_*.csv as bronze tables
dbt run                  # builds staging -> intermediate -> marts
dbt test                 # generic tests (schema.yml) + the quarantine gate
dbt snapshot              # SCD2 snapshot of dim_customers
dbt docs generate && dbt docs serve   # lineage graph + column docs
```
